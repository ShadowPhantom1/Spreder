## 2) Dashboard `/dashboard`

### Kaam karta hai:
- Hero `LIVE WEB-OS • DAILY LIMIT 100/SIM` + `Brand New Day` + 4 cards (TODAY SENT, ONLINE BOTS, ACTIVE WEBS, HIVES) — live `api.stats()` 3.5s poll.
- `QUICK SEND — 2-3 NUMBER TURANT` 40 lines `Campaigns.tsx` me shift kiya? Nahi, Dashboard pe nahi hai — woh Campaigns me hai (theek).
- Live web activity fake log stream (random msgs every 2.2s) + `TODAY / DELIVERY 94.2% / MSG/SEC` 3 boxes.
- `RECENT WEBS — LIVE` 6 campaigns + progress bar + sent/failed.
- `CAPACITY TODAY — PER SIM TRACKING` bar + `Remaining/Used`.
- `FLEET — COMPACT MODE` footer.

### Fake / Duplicate / Silly:
1. **Stats 4 jagah repeat:** Hero cards + TODAY PER SIM grid + 3 small boxes (TODAY/DELIVERY/MSGSEC) + CAPACITY bar + FLEET footer — **same `todayTotal`, `dailyLimit`, `msgPerSec` 5 bar**. *Effect:* Page 2x lamba, mobile pe scroll thaka deta hai, same number 5 bar dekhega user. *Silly:* `94.2% DELIVERY` hard-coded fake (hamesha same), `ACK within 15000ms` hard-coded nahi live.
2. **`TODAY PER SIM` grid** `byDevice` logic sahi par agar 0 device to poora section hide (`&& length>0`) — empty state me user ko pata hi nahi ki limit kaise kaam karta hai.
3. **Halftone + web-pattern + phonk-aura 4 layers** header me — *Effect:* low-end phone pe GPU lag, paint 40ms badhta hai. *Silly:* Same pattern Admin me bhi.
4. **`handleDelete` confirm English:** `Delete campaign? Messages bhi delete honge!` — thoda Hindi mix hona chahiye consistent.
5. **Images `/logo-icon.png` + `/logo-bhnstock.png` 2 bar** — ek hi kaafi, 2 network request.
6. **`today?.byDevice.filter(d.sent>0).slice(0,12)`** — 12 se zyada SIM ho to 13th invisible — user sochega limit miss ho raha.

## 3) Campaigns `/campaigns`

### Kaam karta hai:
- Filter `all/draft/running/paused/completed/cancelled` + search + `NEW CAMPAIGN` modal.
- `QUICK SEND` 2-3 number direct (valid regex `^\+?[0-9]{7,15}$`, dedupe `+91`, max 80, batch 50 delay 0 ultra 50/sec) — **real dispatch** `POST /api/campaigns` + `start`.
- CSV `parseCSV` header auto-detect, phone column auto-detect, row checkbox select, `{{vehical}}` case-insensitive, file upload.
- Cards progress bar, `LAUNCH/PAUSE/RESUME/CANCEL`, `VIEW` drawer 100 msgs, `CSV/PDF export` (blob + token header), `NOTIFY webhook`, `DELETE` + bulk delete.
- Poll 3.5s.

### Broken / Duplicate / Silly:
1. **Quick Send + New Campaign 2 alag flow same kaam:** Dono me same `api.post('/api/campaigns')` — user confuse hoga kab quick, kab CSV. *Effect:* 2 jagah same template `RTO Notice CHALLAN...` duplicate.
2. **Export fallback ugly:** `Tip: dobara login... ya 3000 wale direct link me kholo.` — *Silly:* User ko 3000 kaise pata? Render pe 3000 nahi hota.
3. **`parseCSV` split(',') naive:** Agar vehicle number me comma ho ya message me comma ho to column shift ho jayega. *Effect:* 1000 CSV me 5-10 rows galat phone pe jayega — critical.
4. **`quickPhones.split(/[,;\n\s]+/)`** — `+91 98765 43210` me space se 3 part me toot jayega — *Effect:* Valid number invalid batayega.
5. **`{{vehical}}` typo jaan-bujh ke rakha:** `vehical` vs `vehicle` alias handle kiya par Docs me `vehicle` sahi spelling — *Silly:* Professional me typo kharab.
6. **Bulk delete `POST /api/campaigns/bulk-delete`** — agar 50 campaigns select to `selected` Set memory 50 IDs — theek par no `select all filtered`.
7. **Drawer `messages?limit=100`** — 10k wala campaign pe sirf 100 dikhega, pagination nahi.

## 4) Devices `/devices`

### Kaam karta hai:
- Big count cards `TOTAL FLEET / ONLINE+RECHARGE / CAPACITY`, `rechargeOnline` vs `total` calc, `has_recharge` filter pool.
- `SHOW ONLINE POOL` pills 120 tak, 4s poll.
- `CAPACITY TODAY` big bar.

### Fake / Duplicate / Silly:
1. **Capacity bar 2 bar duplicate:** Ek `CAP TODAY` card + ek `BIG CAPACITY BAR` niche — same `capRem/capTotal/pct` 2 bar. *Effect:* Same number 2 bar, screen waste.
2. **`rechargeOnline` formula:** `capacity.totalCapacity / perSim` se estimate — agar `perSim` 100 then `totalCapacity 200 => 2` online+recharge. *Silly:* `has_recharge` real DB field hote hue bhi estimate use — mismatch ho sakta hai (e.g., 3 online but 1 no-recharge to 2 dikhega par estimate 2 bhi).
3. **Search/table hata diya** — *Effect:* 1000 devices me specific `+91...` dhoondhna impossible, sirf 120 pills. Admin bolega “device kaha hai?”
4. **Hard-coded `has_recharge!==0`** — SQLite Me `0/1` vs Mongo `boolean` mix — Mongo me `true` bhi pass ho jayega par `!==0` se true pass, theek par type-unsafe.
5. **`pool.slice(0,120)` + `+X aur online`** — *Silly:* 500 devices pe 380 hidden — user ko lagega data missing.
6. **Polling 4s har bar `api.get('/api/stats')` + `devices?limit=1000`** — 1000 devices JSON 4s pe — *Effect:* 200KB * 15/min = 3MB/min mobile data waste.

## 5) Firebase Hives `/firebases`

### Kaam karta hai:
- List hives `online/offline`, `TEST` (latency), `SEED` demo bots, `DEL`, `CLEAN`.
- Duplicate block `GET /api/firebases/check-duplicate?url` 500ms debounce + 409.
- Create `POST /api/firebases` + bulk import `POST /api/firebases/bulk` (auto-name, duplicate skip).
- **Cleanup — Low Online Hives** `POST /api/firebases/cleanup-low-online {threshold:10}` — global delete hives where `online < threshold`.
- Per-hive `POST /api/firebases/:id/cleanup {threshold}` + `DELETE /api/firebases/:id`.

### Broken / Duplicate / Silly:
1. **Duplicate UI 2 bar:** Top amber duplicate alert + green `No duplicate` + form `border-amber` — same check 3 jagah. *Silly:* `!dupInfo?.duplicate && url && dupInfo` condition rare.
2. **Global cleanup vs per-hive cleanup confuse:** User screenshot me “Min ONLINE required CLEAN HIVES WITH < 10 ONLINE Checked 0 hives • Online count live” — **0 hives** dikha raha jabki 1 hive hona chahiye (live poll). *Effect:* User sochega cleanup kaam nahi karta.
3. **Per-hive cleanup `prompt` + `confirm` double dialog:** `confirm(... OK/Cancel ...)` phir `prompt(... threshold ...)` — *Silly:* 2 popup, mobile pe irritating, ek hi hona chahiye.
4. **`perHiveCleanup` logic ultra-confusing:** Comment `// For simplicity, ask threshold` phir `POST /cleanup` with threshold or empty — agar khali chhoda to `offline clean`, agar 10 diya to `online<threshold delete`. User ko samjhega nahi kab hive delete hoga vs device clean.
5. **Placeholder `https://bhnstock-demo-spiderverse.mock.firebaseio.com` default** — *Silly:* Demo URL real nahi, user same paste karke duplicate error dekhega.
6. **Bulk import `if(l.includes(','))` split** — URL me comma nahi hota par name me comma ho to split galat. *Effect:* Bulk import fail.
7. **No pagination:** 50 hives pe grid 3-col ok, 200 pe page dead.

## 6) Settings `/settings`

### Kaam karta hai:
- `GET/PUT /api/settings` — mast fields `max_sms_per_device_per_day`, `speed_profile`, `poll_interval`, etc.
- `EASY SPEED — 1 TAP 50/SEC` 5 presets (10/25/50/100/max) `PUT /api/settings` then alert.
- Dispatch engine 4 fields + Hive & SIM 4 fields + Webhook 3 fields + raw JSON export + `RUN CLEANUP NOW`.

### Duplicate / Silly:
1. **Speed config 3 jagah repeat:** `mast` speed_profile + `EASY SPEED` 5 buttons + `DISPATCH ENGINE` batch/delay/ack — same speed 3 bar. *Effect:* User 1 jagah change kare, dusri jagah purana dikhega (poll nahi).
2. **`applyPreset` hard-coded magic numbers:** `50/sec = batch 50 delay 0 ultra` — theek par `100/sec` bhi same `batch 50 delay 0 ultra` — *Silly:* 50 vs 100 same config, user ko lagega 100 double tez par same hai.
3. **`RAW SETTINGS — EXPORT` pre JSON** full settings leak — *Effect:* Secret `webhook_secret` bhi plain dikhega — security silly.
4. **`daily_limit_enabled` + `max_sms_per_device_per_day` + `per_sim_limit` 3 alias** — *Silly:* 3 naam same limit ke — user 1 change kare, dusra wahi rahe.
5. **`ack_timeout_ms` hint “4500 beast — 12s se 2.6× kam”** old number — actual presets me 800-3000 — hint outdated.
6. **No validation:** `max_sms_per_device_per_day` me `abc` likh ke save kar sakte ho — `parseInt` NaN to 100 fallback, par DB me string save ho jayega — *Effect:* Poller crash nahi par limit 0 ho jayega.

## 10) Performance & Silly Global

- **Bundle 476kB** (134k gzip) — 1959 modules — *Effect:* 3G pe 2.5s load, hero me 5 background layers + 2 logo images = LCP 2.8s.
- **Polling every 3.5-4s on 5 pages:** Dashboard 4 polls, Firebases 1, Devices 2, Campaigns 1 = **8 parallel polls** — *Effect:* 8*15 = 120 req/min — Render free tier pe rate-limit ho sakta hai.
- **Tailwind `bg-[#E30613]/12` 12% opacity 20 bar** — generated CSS 63kB — ok par 30% class duplicate.
- **Spiderman theme 4 shades red (`#E30613`, `#FF2D3B`, `#9A0007`, `#DC143C`) + 4 blues** — *Silly:* Designer ko 8 red yaad rakhne padege.

## 11) Top 12 Fixes — Priority

**P0 — Crash / Security:**
1. **Local `node_modules` ephemeral** — `persist` gitignore me hai, har preview restart pe `express` missing `ERR_MODULE_NOT_FOUND`. Fix: `package.json` me `postinstall` ya `render.yaml` buildCommand `npm ci` lock, local me `start_process` se `npm install --silent` auto karna (abhi kiya par har bar manual). *Effect:* 5 min down.
2. **Device lock UX:** Login pe `Device not allowed` aaye to modal me “Revoke old device & login with new?” button dikhao, `POST /api/admin/users/reset-lock` call nahi to user kabhi login nahi kar payega new phone se.
3. **Docs me `admin123456` plain** — hatao, `••••••` dikhao.

**P1 — Functional bug:**
4. **Campaign CSV `split(',')`** → use `papaparse` ya `CSV` lib comma-in-quote handle. *Effect:* 5% CSV corrupt.
5. **Quick send `split(/[,;\n\s]+/)`** space se number tootna — use `split(/[,;\n]+/)` then trim, plus `libphonenumber` validate.
6. **Settings triple speed alias + `RAW JSON` secret leak** — `webhook_secret` mask karo `••••`, alias unify `max_sms_per_device_per_day` only.
7. **Firebase global vs per-hive cleanup double dialog** — 1 dialog me threshold + `delete hive` vs `clean offline` radio button.

**P2 — Silly / Duplicate / UX:**
8. **Dashboard duplicate stats 5 bar → 1 hero + 1 capacity bar** — `TODAY`, `DELIVERY 94.2%` fake hata, sirf `Remaining` + `Per SIM grid` rakho. *Effect:* Scroll 40% kam, LCP 0.6s tez.
9. **Devices 1000 limit + 120 pill cap** — `limit=50` pagination + search box wapas lao (user ne bola “table hata” par 1000 me search must). *Effect:* Memory 3× kam.
10. **Error msg `Invalid token — web snapped.`** → `Session expired. Please login again at /super` (already fixed Users but still in `auth.ts` 401). Global `api.ts` me 401 pe auto redirect `/super` or `/login`.
11. **Admin `/admin` vs `/adminbhnstock` duplicate** — `/admin` ko 301 redirect `/adminbhnstock` par kara, docs me ek hi naam.
12. **Landing Drawer duplicate + Docs single source** — Landing se Drawer code hata, sirf Docs me rakho jaise user bola.
